# Летопись SMC Sampler

## 2026-10-20: семплы на SMC во время мероприятия

Азату нужна среда для треков: фейдер задаёт громкость, четвёртый ряд запускает файл, лампа горит во время воспроизведения. Уточнил, что повторное нажатие запускает заново, а нижняя Пауза останавливает всё.

Собрано отдельное приложение macOS с восемью слотами. Оно обнаружило Bluetooth-порт SMC; программные проверки прошли. Звук не включали, потому что на маке идёт репетиция. Живая проверка остаётся на перерыв.

По просьбе Азата третий ряд назначен на стоп каждого семпла, затем добавлена индикация наличия файла на этом же ряду. Первая крутилка стала мастером. Проверки выполнены без звука, три загруженных файла восстановились после обновления.

Добавлен остаток времени каждого трека. По уточнению Азата измеритель сигнала встроен прямо в существующую полосу фейдера, под круглым ползунком. Беззвучные проверки прошли, воспроизведение агент не запускал.

Азат попросил видеть сигнал при закрытом фейдере: убрано условие гашения измерителя при нулевой громкости. Добавлены TRIM над дорожками и управление ими крутилками 1–8. Для мастера добавлены кнопки с шагом 5% и обучение нижних стрелок. Звук при проверках не включали.

Обучение стрелок завершено: вниз CC60, вверх CC59. Настройки прочитаны и подтверждены. Азат настроил первый TRIM на −10 dB, значение сохранилось.

### Завершение

⭐ Азат подтвердил: «все работает, кайф, сохраняй и завершаем сессию». Рабочая раскладка, TRIM, мастер, таймеры и индикация приняты. Приложение оставлено работающим, агент звуков не запускал. Подготовлен первый коммит и приватный репозиторий SMCSampler; настройки и пути к трекам сохранены дополнительно в локальный backup-local.

### Записка перед завершением, сохранена для истории

# SMC Sampler: точка продолжения

20.10.2026. Азат проверил и подтвердил: «все работает, кайф». Сессия завершена. Приложение оставлено работающим; не перезапускать во время мероприятия без необходимости.

- 8 слотов, перетаскивание файлов, сохранение путей.
- SMC Bluetooth: фейдеры CC40–47; ряд 2 показывает наличие файла; ряд 3 CC90–97 останавливает свой файл; ряд 4 CC70–77 запускает с начала и горит во время проигрывания.
- Нижняя Пауза CC53: стоп всех. Нижние стрелки: CC60 вниз (−5%), CC59 вверх (+5%), назначения сохранены.
- Крутилки CC30–37: TRIM своего слота −60…0 dB, шаг 1 dB. TRIM сохраняется по слотам.
- Остаток времени над фейдером; измеритель сигнала внутри полосы, обновляется и при закрытом фейдере.
- При запуске звук заблокирован, фейдеры в нуле, мастер 100%.

Публичный репозиторий: https://github.com/ttpa3dhuk/SMCSampler
Сборка: ./build.sh. Проверка без звука: './SMC Sampler.app/Contents/MacOS/SMCSampler' --self-test.
Пути/настройки живут в Application Support и preferences; локальный снимок на конец сессии: backup-local/ (в git не входит).
Открытая задача: постепенно улучшать интерфейс по замечаниям с мероприятий. Конкретных правок пока не выбрали. История: JOURNAL.md; ограничения: README.md. До отмашки никаких звуковых тестов и голосовых команд.
