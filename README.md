# SMC Sampler

Восемь семплов под M-VAVE SMC-Mixer на маке. Сделан для запуска отбивок во время мероприятия: каждый фейдер управляет своим файлом, четвёртый ряд запускает его с начала.

## Запуск

Открой `SMC Sampler.app` в этой папке. Перетащи аудиофайл в нужный слот или нажми «Файл…». Приложение запоминает пути: исходные файлы не переносить и не удалять.

При каждом запуске звук заблокирован, уровни равны нулю. В перерыве разреши звук галочкой и подними нужный фейдер. Выход идёт в системное устройство macOS. Приложение не меняет громкость системы, частоту или настройки других программ.

| Управление | Действие |
| --- | --- |
| Фейдеры 1–8 | Громкость соответствующего файла, 0–100% |
| Четвёртый ряд 1–8 | Запуск с начала, в том числе при повторном нажатии |
| Нижняя кнопка «Пауза» | Стоп всех файлов и сброс на начало |
| Лампа четвёртого ряда | Включается при запуске, выключается после конца или остановки |
| «Назначить кнопку Стоп всё…» | Обучение команде кнопки, если у SMC другой режим; звук при обучении блокируется |

Файлы могут играть одновременно. Повторное нажатие не создаёт второй экземпляр одного файла.

## MIDI

Используется первый порт с именем SMC, Bluetooth предпочтительнее USB. User: CC 40–47 для фейдеров, CC 70–77 для запуска, CC 53 для общего стопа, канал 1. Mackie: Pitch Bend каналов 1–8, ноты 24–31 для запуска. В Mackie нижнюю «Паузу» при необходимости назначить через обучение. Лампы: ноты 24–31, канал 1, velocity 127/0. На контроллере должен быть LED code = 1, как в ранее сохранённой настройке WING.

Список файлов хранится в `~/Library/Application Support/SMCSampler/slots.json`, обученная команда стопа в настройках приложения macOS. Звук не разрешается автоматически после перезапуска.

## Сборка и проверка без звука

```sh
./build.sh
'./SMC Sampler.app/Contents/MacOS/SMCSampler' --self-test
```

Нужны Command Line Tools Xcode. Сторонних библиотек нет: AppKit, AVFoundation, CoreMIDI.

## Мастер, TRIM и индикация файлов

Мастер регулируется кнопками −5% / +5% в окне. Нижние стрелки SMC назначаются через «Назначить стрелки мастера…»: сначала ВНИЗ, затем ВВЕРХ. Одно нажатие даёт 5 процентных пунктов, удержание и отпускание не добавляют шагов. Назначения сохраняются. Во время обучения звук блокируется.

Над каждым треком есть круглая ручка TRIM: от −60 до 0 dB. Ей соответствуют крутилки SMC 1–8 (User CC30–37, 127 = +1 dB, 0 = −1 dB). Например, TRIM −6 dB уменьшает амплитуду примерно вдвое. Уровни TRIM сохраняются по слотам, в том числе при замене файла. Итоговая громкость = TRIM × фейдер × мастер. Первая крутилка больше не меняет мастер.

Второй ряд горит у загруженных файлов, включая остановленные (ноты 8–15, канал 1). Третий ряд выполняет стоп своего семпла, четвёртый запускает и показывает воспроизведение. Для внешней индикации нужен LED code = 1. При закрытии лампы гасятся.

## Время и уровень

Над каждым фейдером показан остаток в минутах и секундах. Последние 10 секунд во время проигрывания выделяются оранжевым; после естественного окончания остаётся 00:00. Стоп сбрасывает позицию и показывает полную длину.

Цветной уровень рисуется прямо внутри полосы фейдера под ползунком, по данным AVAudioPlayer.updateMeters/averagePower, диапазон −60…0 dBFS. Это измеритель сигнала плеера, не замер физического выхода звуковой карты или общей суммы. При остановке полоса серая. При воспроизведении измеритель обновляется и с закрытым фейдером или нулевым мастером; программная блокировка по нулевой громкости убрана. Это показание сигнала файла, а не фактической громкости в зале.

Стрелки подтверждены на подключённом SMC: CC60 = мастер −5%, CC59 = +5%, канал 1. Назначения сохранены в настройках приложения.
