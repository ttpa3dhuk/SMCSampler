# SMC Sampler

Семплер для macOS и M-VAVE SMC-Mixer. Я собрал его перед мероприятием, чтобы запускать отбивки с контроллера: отдельный фейдер на каждый файл, кнопка запуска, кнопка остановки и лампы состояния. На первом мероприятии связка отработала. Дальше хочу постепенно привести в порядок интерфейс.

В приложении восемь слотов. Треки можно перетащить в окно; пути сохраняются между запусками. Несколько треков могут играть одновременно, а повторное нажатие запускает свой файл с начала. Уровни фейдеров тоже сохраняются; мастер каждый раз 100%, звук заблокирован.

## Установка

[Скачать установщик macOS 0.1.0](https://github.com/ttpa3dhuk/SMCSampler/releases/download/v0.1.0/SMC-Sampler-0.1.0-macOS-universal.pkg). Открой PKG и пройди шаги мастера: он установит SMC Sampler в «Программы». Перед обновлением закрой приложение.

В ветке `main` уже 0.2.0: выбор выхода, стоп слота из окна, сохранение уровней и клавиши. Установщик 0.2.0 пока не опубликован.

Для установки через мастер нужен пакет `SMC-Sampler-0.1.0-macOS-universal.pkg`: он помещает приложение в «Программы». Command Line Tools на компьютере пользователя не нужны. Пакет собирается для Apple Silicon и Intel с минимальной macOS 13. На старой macOS и Intel запуск пока не проверен.

Установка поверх прежней копии и открытие окна проверены на рабочем Mac с Apple Silicon. Сохранённые файлы и TRIM остались на месте, звук при запуске заблокирован. Проверка запуска после скачивания с интернета пока не проводилась.

Распространяем без платной учётки Apple Developer, как CueDeck: приложение имеет локальную подпись ad-hoc, установщик без подписи Developer ID и нотариализации. При открытии скачанного пакета или первом запуске Gatekeeper может потребовать ручное разрешение в настройках безопасности macOS. Такая упаковка выбрана намеренно; платная подпись не входит в условия выпуска.

Сборка из исходников требует Xcode Command Line Tools, сторонних библиотек нет:

```sh
git clone https://github.com/ttpa3dhuk/SMCSampler.git
cd SMCSampler
./build.sh
open "SMC Sampler.app"
```

Мастер установки собирается отдельно:

```sh
./package-installer-macos.sh
```

Результат и SHA-256 лежат в `generated/`. Скрипт собирает обе архитектуры во временной папке, выполняет беззвучную проверку и не устанавливает приложение. Существующий пакет не перезаписывает. При обновлении заменяется только само приложение в «Программах»; пользовательские настройки в пакет не входят. Перед обновлением нужно закрыть семплер.

Если позже решим добавить подпись Apple, скрипт уже поддерживает `APP_SIGN_IDENTITY` (Developer ID Application), `INSTALLER_SIGN_IDENTITY` (Developer ID Installer) и `NOTARY_PROFILE` (профиль `notarytool` в Связке ключей). Этот путь пока не проверен с реальными сертификатами. Для обычной сборки эти параметры не нужны.

SMC-Mixer подключается к Mac по Bluetooth MIDI или USB. Приложение предпочитает Bluetooth-порт, если видит оба. При запуске звук заблокирован, мастер 100%, уровни фейдеров возвращаются с прошлого раза; для воспроизведения нужно включить «Разрешить звук» и поднять фейдер. Выход выбирается в окне; системный выход macOS приложение не меняет.

## Раскладка SMC

| Орган | Действие |
| --- | --- |
| Фейдеры 1–8 | Громкость соответствующего слота |
| Крутилки 1–8 | TRIM своего слота: от −60 до 0 dB, шаг 1 dB |
| Второй ряд кнопок | Горит, если в слоте загружен файл |
| Третий ряд | Останавливает свой трек |
| Четвёртый ряд | Запускает свой трек с начала; лампа горит, пока он играет |
| Нижняя «Пауза» | Останавливает все треки |
| Нижние стрелки вниз / вверх | Мастер −5% / +5% за нажатие |

Над каждым фейдером показано, сколько времени осталось. Сигнал трека отображается внутри полосы фейдера, в том числе когда фейдер закрыт, а светлая метка показывает пик. TRIM нужен для выравнивания файлов разной громкости; значение сохраняется для слота.

В моей раскладке SMC работает в User-режиме: фейдеры CC 40–47, крутилки CC 30–37, второй ряд CC 80–87, третий CC 90–97, четвёртый CC 70–77. Стрелки мастера я назначил через кнопку «Назначить стрелки мастера…»; у моего контроллера это CC 60 и CC 59. Если у тебя другая раскладка, стрелки можно назначить заново. Приложение также принимает фейдеры Pitch Bend и кнопки запуска/стопа в Mackie-режиме. Для управления лампами из приложения в настройках SMC нужен LED code = 1.

## Окно и клавиши

| Что | Действие |
| --- | --- |
| «Выход:» внизу окна | устройство вывода для семплера; системный выход macOS не меняется |
| «■» в слоте | стоп этого трека и возврат в начало |
| «▶ С начала» в слоте | запуск по клику, если звук разрешён |
| Esc или Пробел | стоп всё |
| 1–8 | запуск слота с начала |

Переключение выхода останавливает все треки: звуковой движок перезапускается на новом устройстве. Выбор запоминается.

## Что пока есть и чего нет

Приложение рассчитано на восемь слотов. Банки слотов и зацикливание пока не сделаны. Значения TRIM сохраняются по слотам, а не по именам файлов. После перезапуска мастер снова 100%, звук заблокирован, а уровни фейдеров возвращаются. Задержку Bluetooth я пока не измерял.

Код приложения находится в [Sources/main.swift](Sources/main.swift). Беззвучная проверка команд и расчётов:

```sh
'./SMC Sampler.app/Contents/MacOS/SMCSampler' --self-test
```

Отдельная проба звукового тракта подаёт полсекунды цифровой тишины и проверяет, что позиция трека идёт, стоп её сбрасывает, а метры получают данные:

```sh
'./SMC Sampler.app/Contents/MacOS/SMCSampler' --self-test-engine
```

Макет окна можно отрисовать в PNG без показа на экране: `--render-ui путь.png`.

Лицензию пока не добавлял: хочу сначала определиться с условиями использования кода.
