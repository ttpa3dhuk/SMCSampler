# Грабли

- У SMC разные сообщения в User и Mackie. Не считать сохранённую карту доказательством текущего режима: сверять входящие MIDI-команды в окне.
- Лампы четвёртого ряда принимают ноты 24–31. Для внешнего управления нужен LED code = 1 (по проверенной карте LightRig).
- Во время репетиции проверки ограничиваются обработкой команд и интерфейсом. Даже короткий тестовый звук требует отмашки Азата.
- AVAudioPCMBuffer не имеет duration: длительность считается по frameLength / sampleRate.
- Перед сменой устройства движок надо остановить; граф и tap'ы переживают перезапуск, таймлайн — нет, все треки встают.
- Файл декодируется целиком в память: пять минут стерео — около 100 МБ. Для восьми длинных треков это много, тогда нужно потоковое чтение.
- `cacheDisplay` не переносит фон окна. В тёмной теме белый текст на прозрачном фоне пропадает при проверке макета; рисовать пробу в светлой теме на белом.
- Беззвучная проверка не должна зависеть от конфигурации пользователя: пути в слотах и набор устройств на разных маках разные.
- NSPopUpButton может отправить action, пока пересобираются пункты: на время обновления снимать target, иначе приложение само выбирает устройство и пишет настройку.
- Длинное имя файла в узкой карточке обрезается: нужен truncation и полное имя в tooltip.
- Пустой слот лучше показывать одним «＋», а не серыми контролами: меньше шума и понятнее, куда нажимать.
- Для проверки макета через `cacheDisplay` подкладывать подложку-вью с цветом фона: иначе прозрачный фон и белый текст тёмной темы не видно.
