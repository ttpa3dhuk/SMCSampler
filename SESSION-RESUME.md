# SMC Sampler: точка продолжения

27.10.2026. Сессия закрыта. 0.4.1 установлена в /Applications, звук при старте заблокирован; всё запушено в main.

## Сейчас

- `/Applications/SMC Sampler.app` — 0.4.1 (build 7), universal, ad-hoc, root:wheel. Приложение оставлено открытым.
- Интерфейс: MASTER с −/+, переключатель ЗВУК, СТОП ВСЁ; карточки 110 px с номером, TRIM по центру, именем в две строки, таймером, фейдером и иконками ▶/■; пустой слот — только «＋». Внизу: точка SMC, строка ошибок, выход, шестерёнка (обучение кнопок, MIDI-монитор).
- Оформление: заголовок окна скрыт, волосяная линия под шапкой, continuous-скругления, SF Rounded для цифр, подсветка карточки под курсором. Вибрантность отклонена: на сцене важнее плотный контраст.
- Иконка: `Resources/AppIcon.icns`, генератор `icon/make-icon.swift`. macOS 26+ маскирует квадратный рисунок сам, на старых macOS он будет квадратным.
- Проверки: `--self-test` PASS, `--self-test-engine` PASS на трёх маршрутах (цифровая тишина). Файлы, TRIM и уровни на месте.
- Релиз v0.1.0 на GitHub не менялся; PKG 0.4.1 не собран. Временные сборки и копия 0.1.0 удалены; откат — PKG 0.1.0 в `generated/` и git.
