27.10.2026. 0.2.0 установлена в /Applications и открыта; звук при старте заблокирован.

- В `main` версия 0.2.0 (build 3). Новое: выбор устройства выхода в окне, стоп слота «■», сохранение уровней, клавиши Esc/пробел и 1–8, метка пика. Воспроизведение переведено на AVAudioEngine: AVAudioPlayer не умеет выбирать выход, системный выход macOS приложение не меняет.
- Проверки в `/tmp`: `--self-test` PASS (команды, карты, расчёт усиления, конвертация 48 кГц → 44,1 кГц, список устройств), `--self-test-engine` PASS на трёх маршрутах (система, Динамики MacBook Pro, NDI Audio) — полсекунды цифровой тишины, позиция идёт, стоп сбрасывает, метры получают данные. Настройки пользователя не изменились.
- `/Applications/SMC Sampler.app` — 0.2.0 (build 3), universal, подпись ad-hoc, владелец root:wheel. Старая 0.1.0 скопирована в `/private/tmp/smc-backup-0.1.0.app` (временная страховка), установщик 0.1.0 лежит в `generated/`.
- После установки: `--self-test` PASS, файлы и TRIM на месте, прежние настройки не изменились, приложение запущено и держит звуковой движок без ошибок.
- Релиз v0.1.0 на GitHub не менялся; 0.2.0 не публиковали. PKG 0.2.0 не собран.

## Далее

1. Проверить окно и звук в перерыве: выбор выхода, стоп «■», клавиши, восстановление уровней.
2. Собрать PKG 0.2.0, обновить README и релиз — только по отдельной команде.
3. Мелочь на потом: в списке выходов видны виртуальные устройства (NDI Audio, агрегаты) — при желании фильтровать.
4. Открыто: Gatekeeper при первом скачивании, Intel и macOS 13, другой Mac.
