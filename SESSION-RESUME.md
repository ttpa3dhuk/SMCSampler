# SMC Sampler: точка продолжения

27.10.2026. 0.4.1 установлена в /Applications: компактное окно в духе macOS, скрытый заголовок, своя иконка. Звук при старте заблокирован.

## Сейчас

- `/Applications/SMC Sampler.app` — 0.4.1 (build 7), universal, ad-hoc, root:wheel; приложение открыто.
- Интерфейс: заголовок, MASTER с −/+, переключатель ЗВУК, СТОП ВСЁ; карточки 110 px с номером, TRIM по центру (32 px), именем в две строки, таймером, фейдером и иконками ▶/■; пустой слот — только «＋». Внизу: точка SMC, строка ошибок, выход, шестерёнка (обучение кнопок, MIDI-монитор).
- Оформление: заголовок окна скрыт (светофоры поверх контента), волосяная линия под шапкой, continuous-скругления, SF Rounded для цифр, подсветка карточки акцентом под курсором. Вибрантность пробовали и отклонили: на рендере теряется контраст, на сцене важнее плотный фон.
- Проверки: `--self-test` PASS, `--self-test-engine` PASS на трёх маршрутах (цифровая тишина). Файлы, TRIM и уровни на месте. Макеты сняты в `generated/ui-check/` (тёмный и светлый).
- Копия 0.1.0 лежит в `/private/tmp/smc-backup-0.1.0.app`; 0.2.0 заменена без копии, её код в git.
- Иконка: `Resources/AppIcon.icns`, генератор `icon/make-icon.swift`. macOS 26+ маскирует квадратный рисунок сам, на старых macOS он будет квадратным.
- Релиз v0.1.0 на GitHub не менялся; PKG 0.4.1 не собран.
