# SMC Sampler: точка продолжения

20.10.2026. Азат проверил и подтвердил: «все работает, кайф». Сессия завершена. Приложение оставлено работающим; не перезапускать во время мероприятия без необходимости.

- 8 слотов, перетаскивание файлов, сохранение путей.
- SMC Bluetooth: фейдеры CC40–47; ряд 2 показывает наличие файла; ряд 3 CC90–97 останавливает свой файл; ряд 4 CC70–77 запускает с начала и горит во время проигрывания.
- Нижняя Пауза CC53: стоп всех. Нижние стрелки: CC60 вниз (−5%), CC59 вверх (+5%), назначения сохранены.
- Крутилки CC30–37: TRIM своего слота −60…0 dB, шаг 1 dB. TRIM сохраняется по слотам.
- Остаток времени над фейдером; измеритель сигнала внутри полосы, обновляется и при закрытом фейдере.
- При запуске звук заблокирован, фейдеры в нуле, мастер 100%.

Приватный репозиторий: https://github.com/ttpa3dhuk/SMCSampler
Сборка: ./build.sh. Проверка без звука: './SMC Sampler.app/Contents/MacOS/SMCSampler' --self-test.
Пути/настройки живут в Application Support и preferences; локальный снимок на конец сессии: backup-local/ (в git не входит).
Новых задач нет. История: JOURNAL.md; ограничения: README.md. До отмашки никаких звуковых тестов и голосовых команд.
