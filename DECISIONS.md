# Решения

## 001. Отдельное приложение, 20.10.2026

На маке есть REAPER и QLab. Выбрано небольшое приложение AppKit + AVFoundation + CoreMIDI, потому что нужны ровно восемь файлов, фейдеры и обратные лампы без настройки текущего проекта репетиции. Сторонних зависимостей нет. Это первая версия, живой тест ещё впереди.

## 002. Повторный запуск

По просьбе Азата повторное нажатие начинает файл заново. Нижняя Пауза останавливает все файлы. Каждый запуск приложения начинается с блокировки звука и нулевых уровней.

## 003. Финальная раскладка

По уточнениям Азата: ряд 2 показывает загруженный файл, ряд 3 останавливает, ряд 4 запускает. Мастер на нижних стрелках, шаг 5%; энкодеры 1–8 регулируют TRIM. Измеритель нужен и при закрытом фейдере.
